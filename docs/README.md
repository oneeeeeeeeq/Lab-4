# Описание библиотеки
Данная библиотека состоит из функций, позволяющих высчитывать площадь и периметр таких фигур, как квадрат, круг, прямоугольник, треугольник. 
# Формулы, встречающиеся в функциях
## Площадь
- Круга: S = πR² 
- Прямоугольника: S = ab
- Квадрата: S = a²
- Треугольника: S = a * h / 2
## Периметр
- Круга: P = 2πR
- Прямоугольника: P = 2a + 2b
- Квадрата: P = 4a
- Треугольника: P = a + b + c

# Примеры вызова функций и их описание
## Для квадрата
- square_area(11) *Данная функция возвращает площадь квадрата по длине его стороны, используя формулу площади квадрата (P = 4a)*
- square_perimeter(3) *Данная функция возвращает периметр квадрата по длине его стороны, используя формулу периметра квадрата (P = 4a)*

## Для круга
- circle_area(9) *Данная функция возвращает площадь круга по его радиусу, используя формулу площади круга (S = πR²)*
- circle_perimeter(7) *Данная функция возвращает длину окружности по её радиусу, используя формулу длины окружности (P = 2πR)*

## Для прямоугольника
- rectangle_area(5, 8) *Данная функция возвращает площадь прямоугольника по длинам его смежных сторон, используя формулу площади прямоугольника (S = ab)*
- rectangle_perimeter(11, 18) *Данная функция возвращает периметр прямоугольника по длинам его смежных сторон, используя формулу периметра прямоугольника (P = 2a + 2b)*

## Для треугольника
- triangle_area(5, 15) *Данная функция возвращает площадь треугольника по длинам его основания и высоты, используя формулу площади треугольника (S = a * h / 2)*
- triangle_perimeter(8, 11, 9) *Данная функция возвращает периметр треугольника по длинам его сторон, используя формулу периметра треугольника (P = a + b + с)*
